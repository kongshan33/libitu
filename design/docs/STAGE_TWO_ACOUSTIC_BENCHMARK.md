# Stage 2 离线声学基准与结果契约

状态：2026-09-13 已实现第一阶段工具和公开种子；人工金标、检测器及产品准确率验证未完成。

可执行入口、目录与命令见 [基准 README](../../apps/api/benchmarks/acoustics/v1/README.md)。使用现有 API Python/Pydantic 环境，独立于在线 API、参考采集和录音 UI。

本轮交付：

- 版本化 manifest/result 及导出 JSON Schema，明确规则候选、人工标注、参考观测和学习者观测的证据身份。
- 16 条公开许可真实语音、4 位成人说话人、约 49 秒，8 条参考与 8 条中国英语学习者语音；全部 dev，文本未配对。
- 原始音频位于忽略的本地缓存，提交来源锁、许可、原始记录 ID、文本和音频哈希；可复现恢复，不上传或训练。
- 64 个 pending 标注任务、双人独立/仲裁操作规范及另行控制采集的 256 条计划。当前已完成现象金标为 0；不能把计划和待标注任务算成已采集/已检测结果。
- 离线完整性、分组防泄漏、结果身份、证据 gate、标量误差/覆盖率和目标级分类评测；未运行时明确 not_evaluated，缺预测不算阴性。

数据量扩展与标注必须继续执行，才能建立可用于算法质量判断的基准。公开语料原有发音评分不是 Libitu 的 connected-speech 标签。模型规则、ASR、字幕和强制对齐器输出也不能替代人工真值。

第一版发布策略不变：先做可复查的测量，再经逐现象验证开放检测；参考侧规则提示不能称为声学确认，用户侧不得从 VAD 连续或相似 F0 推断 Sound 通过。Drop-D 作为 Elision 子类，12 个检测项目不生成跨项总分。置信度仅在存在校准依据时填写，无证据用 null。

这一离线工作可与文件参考 F1–F4 并行，未提前完成它们或 M4b。MFA/Parselmouth/ASR、服务器媒体处理、人工标注和充分的独立测试集仍在后续范围。Glossika 尚无本项目使用授权记录，不纳入已许可种子。
