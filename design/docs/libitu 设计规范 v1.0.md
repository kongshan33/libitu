# libitu 设计规范 v1.0

ElevenLabs 风格 · 适用于 Stage 1 摄取、选段、Stage 2 跟读 · 2026-10-24

## 1. 设计原则

1. **安静**:近乎单色,白底黑字,靠留白和字号层级区分信息,不靠描边、阴影和多种颜色。
2. **内容是主角**:Stage 1 的主角是转写和语料,Stage 2 的主角是声音和录音,界面本身要退后。
3. **音频是视觉核心**:波形、播放游标、录音按钮是产品最有辨识度的视觉元素,优先投入设计精力。
4. **颜色有语义**:紫色是唯一的品牌色,只表示「当前位置 / 已选中 / 已播放」,不用来装饰。
5. **不泄露答案**:Stage 2 默认隐藏文字,视频字幕必须关闭或遮挡,任何组件都不能把待跟读的句子直接显示出来。

## 2. 色彩

### 2.1 中性色

| Token | Hex | 用途 |
| --- | --- | --- |
| `--ink` | `#0C0A09` | 主文字、主按钮背景、当前 Stage 胶囊 |
| `--ink-2` | `#44403C` | 导航次级链接 |
| `--ink-3` | `#57534E` | 摘要、卡片说明、辅助正文 |
| `--muted` | `#78716C` | 次级文字、时间戳、未激活项。**这是允许用于文字的最浅灰**(白底对比度约 4.8:1) |
| `--line-strong` | `#D6D3D1` | 描边按钮、虚线框、空心圆点、波形未播放部分 |
| `--line` | `#E7E5E4` | 进度条底色、时间轴未选中段 |
| `--line-soft` | `#F0EEEC` | 区域分割线、隐藏词块底色 |
| `--surface` | `#FAFAF9` | 卡片、音频条底色 |
| `--bg` | `#FFFFFF` | 页面底色 |
| `--video-bg` | `#1C1917` | 视频窗口底色 |

### 2.2 品牌色

| Token | Hex | 白底对比度 |
| --- | --- | --- |
| `--brand` | `#5A43D6` | 约 6.6:1 |

**紫色允许出现的位置(全部清单):**

- logo 文字 `libitu.`
- 当前逻辑节点的小圆点
- 转写里的高亮下划线(实线 = chunk,虚线 = idiom / 结构)
- 右侧标签页的选中下划线
- 视频和音频的播放进度
- 选段页:时间轴选中段、卡片选中描边、Recommended 标签
- Stage 2:句子进度条的当前段、波形已播放部分

**紫色不允许出现的位置:**

- 主按钮、导航胶囊、录音按钮(这些保持黑色)
- 卡片底色、大面积背景、渐变
- 每个选段各分配一种颜色(旧版五色时间轴已废弃)

### 2.3 使用规则

- 同一屏内,彩色元素(紫色)不超过 3 处同时出现。
- 不使用饱和的红、橙、绿作为装饰。错误和警告状态另行定义,出现时才引入。
- 浅灰 `#A8A29E` 及更浅的颜色**不得用于文字**,只能用于装饰线。

## 3. 字体

字体族:`Inter`,回退 `system-ui, sans-serif`。时间戳和技术标注用 `ui-monospace, Menlo, monospace`。

| 角色 | 字号 / 行高 | 字重 | 字距 | 颜色 |
| --- | --- | --- | --- | --- |
| 页面标题 H1 | 30 / 1.25 | 500 | -0.02em | `--ink` |
| 区块标题 H2 | 22 / 1.3 | 500 | -0.01em | `--ink` |
| 卡片标题 H3 | 17 / 1.35 | 500 | -0.01em | `--ink` |
| 转写正文 | 18 / 1.6 | 400 | 0 | 当前行 `--ink`,其余 `--muted` |
| 正文 / 摘要 | 15 / 1.6 | 400 | 0 | `--ink-3` |
| 说明文字 | 13–14 / 1.5 | 400 | 0 | `--ink-3` 或 `--muted` |
| 标签(全大写小标题) | 11 | 500 | 0.08em | `--muted` |
| 时间戳 / 元信息 | 12 mono | 400 | 0 | `--muted` |

原则:标题用 500,不全部加粗;层级靠字号和颜色拉开,不靠字重堆叠。

## 4. 间距与布局

- 基础单位 4px。常用间距:4 / 8 / 12 / 16 / 20 / 24 / 32 / 48。
- 页面最大宽度 1280px,居中。
- 顶栏高度 64px,左右内边距 32px,底部 1px `--line-soft` 分割线。
- 底部操作栏:内边距 16px 32px,顶部 1px `--line-soft` 分割线。

### 页面骨架

| 页面 | 结构 |
| --- | --- |
| Stage 1 摄取 | 三栏网格:左 268px(逻辑流) / 中 1fr(视频、音频条、转写) / 右 332px(语料),底部固定操作栏 |
| 选段 | 单栏:标题行 → 时间轴 → 3 列卡片网格(间距 16px)→ 底部操作栏 |
| Stage 2 跟读 | 单栏居中,内容宽 680px,顶部子标题行 + 模式切换 |

## 5. 圆角、边框、阴影

| 元素 | 圆角 |
| --- | --- |
| 按钮、导航胶囊、音频条、标签 | 999px(全圆) |
| 视频窗口 | 16px |
| 卡片(语料卡、选段卡) | 14px |
| 空心占位框、时间轴分段、隐藏词块 | 8–12px |

- **阴影:全站不使用。**
- **边框:尽量不用。** 区域用 `--surface` 浅底区分;仅在以下情况使用 1px 描边:描边按钮(`--line-strong`)、选中卡片(`--brand` 1.5px)、空状态虚线框。

## 6. 图标

- 单线风格,线宽 1.5px,圆头端点,推荐 Lucide。
- 尺寸:行内 16px,按钮内 20–28px。
- 颜色跟随文字色;白色图标只出现在黑色按钮上。
- 纯装饰图标加 `aria-hidden="true"`,可点击图标必须有 `aria-label`。

## 7. 组件

### 7.1 按钮

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| 主按钮 | 黑底 `--ink`、白字、全圆、内边距 14px 26px、15px / 500 | 每屏仅一个:Choose a segment to shadow、Begin Stage 2 |
| 次按钮 | 透明底、1px `--line-strong` 描边、全圆、内边距 8px 14px、13px | Back、Open loadout、Back to segments |
| 文字链接 | `--ink-2`,14px,内边距 8px 10px | Corpus、My learning |
| 圆形播放 | 36px 黑色圆,白色三角 | 音频条播放 |
| 视频大播放 | 64px 白色圆,黑色三角 | 视频窗口中央 |
| 录音按钮 | 76px 黑色圆,白色麦克风图标 | Stage 2 主操作 |

禁用态:背景 `--line`,文字 `--muted`,不可用透明度表达。

### 7.2 顶栏与 Stage 步骤

- 左:logo(紫色,600)+ 视频标题(14px,`--muted`,单行省略,最大 380px)。
- 中:Stage 1 / 2 / 3 三个胶囊。当前项 = 黑底白字,其余 = `--muted` 文字无底。
- 右:Corpus、My learning(文字链接)+ 32px 黑色圆形头像(白色首字母)。
- Stage 与 Corpus / My learning 性质不同,用样式区分:前者是带底色的步骤,后者是纯文字。

### 7.3 逻辑流列表项(Stage 1 左栏)

- 三列:6px 圆点 / 标题 + 说明 / 时间戳。
- 默认:圆点 `--line-strong`,文字 `--muted`。
- 当前:圆点 `--brand`,标题 `--ink` 加粗 600。不加底色块。
- 标题 14px / 500,说明 12.5px / 1.5。

### 7.4 视频窗口

- 16:9,深色底 `--video-bg`,圆角 16px,内嵌 YouTube 播放器。
- 左上角:标题(白,14px / 500)+ 频道名(`#D6D3D1`,12px)。
- 中央:64px 白色圆形播放按钮。
- 底部:4px 进度条,轨道 `#44403C`,已播放 `--brand`。
- Stage 1 保留完整视频窗口。Stage 2 缩小为 320×180,并关闭字幕(见 8.3)。

### 7.5 参考音频条

- 底色 `--surface`,全圆,内边距 12px 16px。
- 内容:36px 黑色播放按钮 + 波形 + 右侧 mono 文案 `Reference audio · 当前 / 总时长`。
- 波形:40px 高,圆头竖线,线宽 3,间距 8;已播放部分 `--brand`,未播放 `--line-strong`。

### 7.6 转写行

- 两列:48px 时间戳(mono)/ 正文,行间距 14px,正文 18px / 1.6。
- 当前行 `--ink`,其余 `--muted`。
- 高亮:不使用底色和边框,只用下划线 2px。chunk 为 `--brand` 实线,idiom / 结构为 `--brand` 虚线。

### 7.7 语料卡与标签页

- 标签页:Chunks / Idioms / Structures / Saved,14px,默认 `--muted`;选中项 `--ink`、500、底部 2px `--brand` 下划线;整排底部 1px `--line-soft`。
- 小标题 `EXTRACTED THIS VIDEO`:标签样式(11px,0.08em)。
- 卡片:底 `--surface`,圆角 14px,内边距 18px,无描边。
  - 引文 15px / 500;说明 13px `--ink-3`;元信息 12px `--muted`(类型标签、时间、等级、保存状态用 `·` 连接,不用彩色标签)。
- 底部「已保存」行:13px 文案 + 次按钮 Open loadout。

### 7.8 选段时间轴与卡片

- 时间轴:5 段并排,间距 4px,宽度按时长比例;高 40px,圆角 8px。未选中 `--line`、文字 `--ink-3`;选中 `--brand`、白字。下方 mono 起始时间对齐各段。
- 选段卡片:3 列网格,底 `--surface`,圆角 14px,内边距 22px,最小高度 196px。
  - 结构:(可选)Recommended 标签 → 标题 H3 → mono 元信息(起止 · 时长 · 词数)→ 引文摘录(14px,`--ink-3`)→ 难度。
  - 选中:底变白,1.5px `--brand` 描边。
  - Recommended 标签:`--brand` 底、白字、11px / 500、全圆。
- 难度:`●●○` 三点 + 文字(Medium / Dense)。实心点 `--ink`,空心点 `--line-strong`。同一信息只表达一次,不再同时用彩色点和文字。
- 词汇来源缩写(LK、WK 等)不再作为彩色徽章展示;需要时改为 hover 提示完整含义。

### 7.9 句子进度条(Stage 2)

- 每句一段,高 3px,圆角 2px,间距 6px,总宽 680px。
- 已完成 / 当前 = `--brand`,未开始 = `--line`。
- 下方一行:左 `Round 1 · Sentence 1 of 11`,右 `No scoring while you practice`,13px `--muted`。

### 7.10 隐藏词块

- 圆角 8px,高 30px,底 `--line-soft`,宽度与原词长度成比例,居中换行排列,间距 8px。
- 这是「被遮住的字」,不是加载骨架,不做闪烁动画。
- 可点击揭示单个词(`aria-label="Reveal word"`),揭示后显示原词,`--ink`。
- 下方说明 `Text hidden · tap a block to reveal`。

### 7.11 录音区

- 两条波形上下排列:`Reference`(参考)与 `Your take`(你的录音),左侧 84px 标签,右侧波形。
- 未录音时,`Your take` 为 1px 虚线空框,文案 `Ready when you are`。
- 录音按钮:76px 黑色圆,居中,上方留 36px。
- 指令文案 15px:`Listen to the sentence, then say it right away.`;下方 13px `--muted`:`Pause discards the unfinished take.`

## 8. 页面规范

### 8.1 Stage 1 · Ingest

1. 中栏自上而下:H1 标题 → 摘要 → **视频窗口(16:9)** → 参考音频条 → 转写。
2. 左栏逻辑流跟随播放自动高亮当前节点。
3. 右栏语料卡与转写中的高亮一一对应(点击高亮定位到卡片)。
4. 底部操作栏:左 `Analysis complete · 5 practice segments ready`,右 `All segments under 5 minutes` + 主按钮。
5. 吉祥物 / 悬浮头像不得遮挡任何文字内容。固定在页面角落,并提供关闭入口。

### 8.2 选段

1. 标题行 + 次按钮 Back。
2. 时间轴 → 5 张卡片 → 底部栏。
3. 推荐段默认选中,底部主按钮随之可用;未选中时主按钮为禁用态。

### 8.3 Stage 2 · Shadow

1. 子标题行:左 `STAGE 2 · SHADOW` 标签 + H2 段落名;右 Quick / Detailed / Review 切换(当前项黑底白字)+ Back to segments。
2. 句子进度 → 缩小视频(320×180,圆角 16px)→ 两条波形 → 隐藏词块 → 录音按钮 → 指令文案。
3. **视频字幕必须关闭**,或用遮罩盖住字幕区域;跟读时画面里不得出现英文或中文字幕。
4. 视频控件(标题栏、CC、设置、水印)在跟读阶段尽量隐藏,避免与波形争夺注意力。

## 9. 状态与动效

- 动效克制:时长 120–200ms,`ease-out`,只用于颜色、透明度、位置的变化。
- 悬停:次按钮背景变 `--surface`;卡片背景变 `--line-soft`;不使用缩放和位移。
- 焦点:2px `--brand` 外轮廓,偏移 2px,键盘操作时必须可见。
- 波形:播放时游标线沿波形匀速移动,已播放部分变 `--brand`;录音时 `Your take` 实时绘制,已绘制部分为 `--ink`。
- 加载:使用文字状态(如 `Preparing reference audio…`)或细进度条,不使用旋转图标与骨架闪烁。

## 10. 无障碍

- 所有文字对比度至少 4.5:1;`--muted` 是允许的最浅文字色。
- 可点击区域最小 32×32px,移动端 44×44px。
- 图标按钮必须有 `aria-label`;装饰性波形和图标设置 `aria-hidden="true"`。
- 不单靠颜色传达信息:chunk 与 idiom 用实线 / 虚线区分,难度用点数 + 文字,选中用描边 + 底色。
- 键盘:空格播放 / 暂停,Tab 顺序与视觉顺序一致。

## 11. 文案

- 英文界面沿用现有文案,首字母大写,不用感叹号。
- 指令用祈使句,一句话说完(`Listen to the sentence, then say it right away.`)。
- 时间格式 `m:ss`,时长 `1m 20s`,词数 `181 words`。
- 引用原句使用弯引号 “ ”,撇号使用 ’。

## 13. 与旧版相比的主要变化

| 项目 | 旧版 | 新版 |
| --- | --- | --- |
| 色彩 | 紫、橙、绿、蓝多色并存 | 黑白灰 + 单一紫色品牌色 |
| 选段时间轴 | 每段一种饱和色 | 灰阶,选中段紫色 |
| 卡片 | 淡紫底 + 描边 | `--surface` 浅灰底,无描边 |

| 吉祥物 | 悬浮在内容上,遮挡文字 | 固定角落,不遮挡 |
