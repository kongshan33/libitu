## 本轮交付

按照 `design/prototypes/toneflow_stage2_three_layer.html` 的结构，Sound、Rhythm、Melody 都展示同一历史练习中的 Reference / Your recording。左右对应的是同一句、同一词位置；不能把历史录音与当前播放的其他原音混合。右侧展示分项反馈，选词查看测量值。切句清除旧对比，刷新从服务器恢复，切换 layer 不重新分析。

- Sound：现已接入元音时长、候选辅音—元音边界的停顿测量及实验性接近度。十个现象筛选项保留各自状态，未支持的项目不显示分数。词典 IPA 和规则提示放在可展开的独立区域，不冒充实际发音。
- Rhythm：双行文本上方是三个大小、深浅的实心琥珀色音节圆点；文本后方是停顿竖线和秒数；词卡展示各自的时长及条形。圆点来自词典约束的音节重音，不是检测到的句子重音。没有重复的 speech-and-pauses 时间轴。
- Melody：两条相对音高曲线共享逐词坐标，词卡显示各自的半音值和词内走向。每词等宽，缺失采样保留间断，不把绝对音高差当成语调错误。手机端对比区域可横向滚动，反馈位于下方。

## 检测与评分的实际边界

| 项目 | 当前可用证据／计算 | 当前不能声称的结论 |
|---|---|---|
| Vowel length | 双方 MFA 对齐元音的区间时长，按词求和后比较；元音标签序列必须一致 | 元音发对了、长短元音类别正确、实际 IPA |
| Linking | 根据原音对齐标签选择辅音—元音候选边界，对比已定位的 VAD 停顿时长 | 没有停顿就一定发生了连读 |
| Weak forms | 未支持，空分数 | 单凭短时长不能判断弱读或 schwa |
| Flap-T | 未支持，空分数 | 短 /t/、/d/ 对齐区间不能证明 [ɾ] |
| Elision / Drop-D | 未支持，空分数 | 强制对齐不能区分省音、未释放爆破音、对齐错误 |
| Assimilation | 未支持，空分数 | 需要独立音素变化证据 |
| Glottal stop | 未支持，空分数 | F0 中断不能证明喉塞音 |
| H-dropping | 未支持，空分数 | 低能量不能证明 /h/ 脱落 |
| Final voicing | 未支持，空分数 | 无 F0 不能证明清化 |

本轮没有 Sound 总分，没有发音正确率或已验证的现象分类器。每项均保留 `realization: not_evaluated`。下一阶段需逐项训练／评估实际发音检测器，并完成独立标注集；现有 64 个 benchmark 标注任务尚未完成。模型未验证前不得把规则命中率或测量相似度当作检测准确率。

## 实验性接近度计算

所有分数为 0–100 的工程接近度，不是准确率、置信度、CEFR 或学习水平；尚未与人工评价校准。有效但不同的说话方式可能得到不同数值。

1. 两路语音均通过独立 ASR 内容核对及 MFA 对齐，词序列与句子快照一致；不能有不足语音、低能量或削波问题。至少 3 个词，每词 25–3000 ms。
2. 语速比例为各词 `用户时长 / 原音时长` 的中位数。元音和单词时长比较前，将用户时长除以此比例。
3. 元音时长：单个元音需在 25–800 ms，标签去掉重音数字后逐一一致；每词元音总时长的接近度为 `100 × min(a,b) / max(a,b)`。
4. 边界停顿：`100 × exp(-abs(a-b)/200ms)`。0 仅表示短词间间隙被一个连续 VAD 语音区间覆盖；未知边界为 null。已检测停顿只在可唯一映射到词间时使用。该分项比较停顿，不判断连读。
5. Rhythm：可比较的词时长接近度与边界停顿接近度取平均。覆盖率分母是 `2N-1`；不检测句子重音。
6. Melody：相对各自句子中位 F0 的半音，在每词 5 个对应区间比较；每对为 `100 × exp(-abs(a-b)/3st)`。至少 9 对有效采样，至少 3 个词各有 3 对有效采样。覆盖率分母取两路有效采样位置并集与 `3N` 中较大者；整句音高不足时不评分。
7. 各分项至少 60% 候选测量可比才能发布分数，并保存 `compared/eligible`。无目标、缺证据、未支持项目保持 null，不能填 0 或 100。局部可用测量仍可显示。

这些阈值是可追溯的初始工程值，后续校准必须升级公式版本。

## 数据与兼容性

既有异步任务继续执行：临时私有上传 → ASR 核对 → MFA → VAD/F0 → 逐词测量 → 成对评估 → 保存 JSONB。新增 `phones`、`boundary_pause_ms` 和 `assessment`，不新增表或数据库迁移。

新任务使用 `practice-comparison-v2`。旧结果可读，不自动补算；旧临时音频可能已经清理，用户需录制新一遍获得新增测量。worker 拒绝与当前分析版本／模型配置不一致的待处理任务，不给旧结果换标签。删除或撤销原音后，读取结果同时隐藏 reference 与包含其测量值的 assessment。用户自己的测量仍可用。

上述服务器持久化对比依赖已注册且仍获许可的文件式原音。2026-09-26 新增的[浏览器本地对齐](STAGE_TWO_LOCAL_ALIGNMENT.md)将采集原音接入逐词／音素定位，并在页面中与匹配的用户逐词结果并排显示，不需要服务器文件来源注册。原音及其对齐结果仍留在浏览器；跨引擎分数留空，内容未独立核对。普通 YouTube／本地缓冲原音不会因此自动上传或变成服务器参考素材。

## 验证

2026-09-23：根目录 `pnpm lint`、`pnpm build`、`pnpm test` 通过，共 756 项（447 API + 197 web + 112 extension）。新版对比及原有 Sound guide 浏览器回归均通过桌面／手机检查；已人工检查分数、两路曲线、实心圆点与窄屏布局。

- 自动化覆盖相同输入、语速归一化、时长／停顿／音高差异、内容不符、错误对齐、短词、质量问题、未知边界、元音标签不同、稀疏音高、无目标，以及撤销原音后嵌套评分隐藏。
- 浏览器用固定 API 数据验证桌面／手机双行、Sound 筛选、空分数、词典重音圆点、暂停标记、历史恢复、切句隔离和删除。它验证交互，不证明声学准确性。
- 真实本地 ASR/MFA + 托管队列／私有存储合成语音闭环已完成，确认相符与不相符文本、结果保存、所有权、撤销和清理。合成的近同源音频得到 Rhythm 99.3、Melody 98.3、元音时长 100；仅说明链路与持久化正常，不是准确率评估。测试行和文件已移除。

## 技术依据

[MFA 官方指南](https://montreal-forced-aligner.readthedocs.io/en/v3.4.0/user_guide/index.html)描述的是给定文本和词典约束的强制对齐；因此本实现不把其音素标签视为独立识别出的实际发音。[Praat 对 voice breaks 的说明](https://uvafon.hum.uva.nl/praat/manual/Voice_1__Voice_breaks.html)也区分无周期区间和具体发声成因，不能用音高缺失直接判喉塞音。现有 [Supabase JSONB](https://supabase.com/docs/guides/database/json) 保存版本化结果；字段校验由 Pydantic 完成。
