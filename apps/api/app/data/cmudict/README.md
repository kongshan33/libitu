[cmusphinx/cmudict commit 74790861f652b15e4ac49015a90074ad62a27690](https://github.com/cmusphinx/cmudict/tree/74790861f652b15e4ac49015a90074ad62a27690),

The small project-owned parser verifies the dictionary hash before loading it.
No Python wrapper, GPL wrapper code, network download or speech model is used.
Dictionary lexical pronunciations do not establish a speaker's accent, sentence
stress, or actual connected-speech realization. Changes require updating this
provenance, the checked hash, lexicon version, and regression fixtures together.
