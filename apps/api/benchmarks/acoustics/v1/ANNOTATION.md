# 声学离线基准 v1：双人标注规范

本规范用于建立可追溯的离线测量基准和现象标签。它不证明某个检测器已经有效，也不为学习者定义唯一正确的口音。`collection_plan.json` 是尚未执行的 256 条录音采集计划；公开许可语音种子、实际采集录音、合成测试信号须分别清点，不能互相补足数量。

## 1. 标注单位与证据边界

- 固定音频角色为 `reference` / `learner`。两侧分别听辨、定位、测量和标注；参考侧的标签不能复制给学习者，流利说话人也不自动获得 `present` 标签。
- 一个目标表示一段音频上的一个现象及其词范围。规则、词典和采集提示仅定位 **candidate**，没有音频证据时没有实际发生的结论。补充规则未覆盖的目标时也需记录位置，避免只评估规则已命中的样本。
- 时间一律是实际音频文件内、从 0 开始的秒数，区间采用 `[start_seconds, end_seconds)`。切片或重采样需保持可追溯映射；视频时间、字幕偏移与另一条录音的时间不能直接填入。
- `word_start` / `word_end` 为实际核对文本经空白分词后的 0-based、half-open 范围；标点仍附在原 token 上。例如 `I told him today.` 中 `told him` 为 `[1, 3)`。重复词按本次出现定位，不按字符串全局匹配。改动核对文本后必须复核全部词索引。
- ASR、字幕、词典音标、MFA 对齐和语言规则都不能充当金标。可以在独立人工听写后辅助核对文本，但字幕结束、下一词开始与强制对齐结果均不等于人工确认的发音边界。
- 本轮范围共 12 项：`vowel_length`、`linking_gap`、`pause`、`f0`、`flap_t`、`weak_form`、`h_drop`、`final_voicing`、`elision`、`assimilation`、`glottal_stop`、`drop_d`。`drop_d` 是 `elision` 的子类；汇总时去重，不能把同一次 /d/ 删除当两个独立成功检测。

## 2. Annotation 状态与标签

| 字段 | 可取值与使用方式 |
|---|---|
| `status` | `pending`：未审；`single_review`：至少一位标注者已审；`adjudicated`：两位独立初标已比较并完成一致确认/分歧仲裁；`synthetic`：只用于 `synthetic_smoke` 中的人工合成信号 |
| `label` | `present` / `absent` / `uncertain` / `not_applicable` / `null` |
| `measurements` | 连续测量列表；无可靠测量时为空，不填推测数值 |
| `annotator_ids` | 匿名且稳定的标注者 ID；完成仲裁至少含两位不同的人，另有仲裁员时也记录其 ID |
| `notes` | 听辨理由、边界疑点、测量工具/版本/设置、质量问题、原始独立记录位置及仲裁决定 |

`pending` 必须使用 `label: null`、`measurements: []`、`annotator_ids: []`。`single_review` / `adjudicated` 至少有一个非空标签或一项测量。纯连续测量可以保留 `label: null`；这不代表未审，需结合 `status` 判断。

标签含义：

- `present`：在已审、可定位目标上有足够声学证据支持该操作性定义；不等于“读对了”。
- `absent`：在同一有效目标上主动审查后，有足够证据判断该现象未发生；不等于“读错了”。未标注、未采到、未运行模型都不是 `absent`。
- `uncertain`：目标可能适用，但遮蔽、边界、特征或两位专家听辨仍不足以可靠判断。仲裁可以正式保留不确定，不强迫二分。
- `not_applicable`：核对后发现没有该现象的有效目标，例如实际说出的词已改变目标语境。单纯低音量、被裁掉或对齐失败通常属于 `uncertain`，不是“不适用”。
- `null`：没有现象二分类标签。时长或 F0 已测量仍可以为 `null`；缺失数值也不能用 0 代替。

可执行的测量对象形式：

```json
{
  "name": "duration_ms",
  "value": 123.4,
  "unit": "ms",
  "interval": {"start_seconds": 0.42, "end_seconds": 0.5434}
}
```

以上仅演示格式，不是一条已标注语音。允许的名称/单位：`duration_ms`、`pause_duration_ms`、`boundary_gap_ms`、`closure_duration_ms` 使用 `ms`；`f0_hz`、`f1_hz`、`f2_hz` 使用 `Hz`；`f0_semitones` 使用 `semitones`；`voicing_ratio` 使用 `ratio`；`intensity_db` 使用 `dB`。`voicing_ratio` 在 0–1 之间。区间存在时不得越过音频末尾；测量区间与数值应可复核。

本轮 schema 要求同一个目标的 `measurements.name` 唯一，不能在同一目标放多个 `f0_hz` 或同名时长记录。F0 的单个 `f0_hz` 记录代表该短测量区间的中心值；若需比较多个可靠窗口，应为每个窗口建立不同的 `target_id`，分别记录区间、标量和标注状态。逐帧曲线序列不在本轮格式与评估范围内。无声、噪声或无法确定基频的区间留空，不填 0 Hz。音高半音的基准必须在 `notes` 中说明，例如 `12 * log2(F0 / 本条已确认有声窗口的中位数)`。未校准麦克风的强度写明为工具定义的相对 dB，不能声称是 dB SPL，也不能跨设备直接比较。

## 3. 独立初标、复核与仲裁流程

1. **登记真实素材。** 确认文件可读、实际时长/采样率/通道数、文件校验和、许可或参加者授权、来源、说话人和 source group。计划中的人或录音只留在计划文件，不能提前写入真实样本清单。公开种子先核对说话人身份是否可信、是否有人声；未人工审听时保持 `pending`。
2. **形成盲审包。** 两位标注者 A/B 使用相同原始音频、规范与随机化片段 ID。隐藏待评估模型的预测、置信度、自动边界及对方标签；先听整句再人工核对文本。完成第一轮听辨后才显示 candidate 目标范围。规则只帮助安排检查位置，不成为标签证据。
3. **独立记录。** A/B 各自保留一份 `single_review` 记录，不相互覆盖。按“整句原速 → 带上下文片段 → 波形/频谱 → 必要的慢速回放 → 原速再听”复核。可用 Praat 等测量软件查看证据，但不得先看被评测检测器输出再修金标。慢速回放只帮助听辨，时长与 F0 从原速原文件测量。
4. **定位与质量检查。** 人工核对发音内容、目标词范围、音素/边界区间及裁切。每个目标独立判断是否可测，不因整条存在噪声就抹掉其他可用目标，也不因 VAD 可用就认定所有声学特征可用。记录吞音、重复、自我修正等实际内容。
5. **先测量，再按定义贴标签。** 优先完成 pause/F0/vowel_length/linking_gap 的连续测量；现象标签另填。工具算出的值需经听辨、波形周期或频谱验证。提取失败留空并说明；不得由目标词预设读音反推出缺失数值。
6. **比较独立结果。** 列出类别分歧与连续测量差异；同时抽查一致样本，避免两位使用同一错误线索。首轮仅用于触发复核的工程阈值：边界或时长相差 >10 ms、F0 相差 >1 半音、voicing ratio 相差 >0.1。即使低于阈值，只要接近判定边界、目标极短或听辨理由冲突，也要复核。这些阈值不是人类真值精度或产品正确率承诺。
7. **仲裁与冻结。** A/B 共同重听并明确记录决定；无法解决的分歧请第三位具语音学训练的仲裁员处理，或保留 `uncertain`。不能简单平均两位不同的音素切分。保存两份初标、仲裁理由和最终 `adjudicated` 记录，再冻结本轮版本。不能把“有两个 ID”当作已完成独立标注的证据。
8. **解盲并运行评估。** 金标冻结后才查看模型结果。后续修正需留下旧记录和修改原因；不能看到模型错误后静默改答案。角色分别报告，纯测量和二分类分别计算，合成信号单独报告。

## 4. 各现象的标注内容

| 现象 | 首轮证据与测量 | 应保留不确定的情况 |
|---|---|---|
| `pause` | 标实际内部非言语间隔的起止及 `pause_duration_ms`；区分气息、塞音闭合、词中无声辅音和录音前后空白。若填写二分类，本版本 `present` 指经人工确认的内部停顿且 ≥200 ms，`absent` 指有效候选处没有达到该条件；200 ms 只是与当前展示一致的操作性阈值，短间隔仍可测量。 | 起止被裁切、背景声掩盖语音、长辅音闭合与停顿难分，或边界不确定范围跨过 200 ms。气息可构成非言语停顿，需在 notes 标出，不要求“全静音”。 |
| `f0` | 优先记录可靠有声窗口上的 `f0_hz` 与区间；每个窗口一个独立 `target_id`，同目标不能重复 `f0_hz`。借助波形周期/谐波复核八度错误。需要时记录有明确基准的 `f0_semitones`。默认 `label: null`，不把“有 F0”解释成“语调正确”。 | 清浊转换、嘎裂声、多说话人/音乐、倍频/半频歧义、可用周期不足。不能插值穿过无声段充当真值；两条录音独立标量测量，不用 DTW 对齐反过来定金标。 |
| `vowel_length` | 人工定位目标元音起止，记录 `duration_ms`；记录元音类别、上下文、重音、句内/句尾位置及实际语速条件。默认 `label: null`。配对词只用于比较同一说话人在可比条件下的时长。 | 元音与近音/鼻音边界不清、弱化到无法分段、裁切、两位边界分歧过大。不能以“浊辅音前理应长 30–50%”代替测量，也不把不同语速的原始时长直接判好坏。 |
| `linking_gap` | 在明确相邻词范围中记录额外边界停顿的 `boundary_gap_ms`。默认只测量、`label: null`；若填写标签，`present` 表示经听辨确认的额外边界间隔，`absent` 表示主动确认没有额外间隔，方向与“连读成功”不同。塞音自身闭合另量，不算额外 gap；0 只用于人工确认无额外间隔的目标。 | 连续信号中词边界无法可靠定位、塞音闭合与词间停顿混淆、过渡重叠或能量过低。无 gap 不能证明插音、变音或所有连读过程正确。 |
| `flap_t` | 用目标 /t/ 语境结合短暂收缩/闭合、周期性与能量变化进行听辨；可记 `closure_duration_ms`、`voicing_ratio`。`present` 是支持 flap-like 实现，`absent` 是明确其他实现。记录重音及词内/跨词环境。 | 仅有标准 /t/ 对齐标签、仅满足 <30 ms、只有/没有 burst、闭合缺失或 glottal/approximant 实现难分均不够。短音可有 transient，持续周期性也不是唯一条件。 |
| `weak_form` | 听辨功能词的实际弱形式及其语境，结合元音质量、时长和相对突出程度。可记 `duration_ms`、经人工确认的 `f1_hz`/`f2_hz`；notes 写实际听到的变体及取样区间。 | 短元音无法稳定估计 formant、元音受邻音强烈影响、语境可接受强读但重音不明。弱读不必是 schwa；固定 F1/F2 框不能作通用判据。 |
| `h_drop` | 在可识别目标中听辨 /h/ 是否保留；检查气声/非周期成分及到元音的过渡。`present` 表示有足够证据支持该 /h/ 删除，`absent` 表示 /h/ 清晰存在。可辅助记录相对 `intensity_db`、周期性比例，说明窗口。 | /h/ 极弱、邻接送气混淆、增益/降噪影响、词和音节边界不清。/h/ 删除后可能直接连接到有声元音，不能把低能量或零能量作为删除定义。 |
| `final_voicing` | 标目标词尾阻碍音实际有声段，记录 `voicing_ratio`（人工确认有声时长/明确目标辅音总时长），以及辅助的前元音 `duration_ms`。二分类仅表示是否有声学上可辨的周期振动，比例仍需独立保留。 | 闭合区间不清、低频噪声误似 voice bar、语尾弱声、部分清化或无爆破。词典“浊辅音”不要求全程有声；没有全程 voice bar 不能判发音错误。 |
| `elision` | 仅为参考侧研究和自听提示建立人工标签：在清楚的预期目标环境中核实实际音流是否省略该段，并记录保留、弱化或删除的声学理由。学习者样本可以人工研究标注，但第一版不得据此启动用户自动检测/评分。 | 单靠对齐器给出零时长、听不清、闭合重叠、同化或弱化到低可见度。声音“没找到”本身不足以支持删除；`absent` 需观察到目标保留。 |
| `assimilation` | 记录边界或词内实际变体及支持的频谱/听辨证据；例如将 /t/+/j/ 的融合与各自保留区分。按参考侧研究项处理，不作首轮学习者自动评分。 | 只有字面语境或规则建议、共发音与类别变化难分、擦音过短、背景遮蔽或口音差异；不得把任何平滑过渡都当成同化。 |
| `glottal_stop` | 检查明确的声门闭合/再起音、周围声门化线索及听辨结果；记录目标与口音条件。作为参考侧研究项。 | 仅有 F0 丢帧、嘎裂声、截断、普通停顿或话筒断音；这些不能单独证明 /ʔ/，未看见波形也不等于声门塞音不存在。 |
| `drop_d` | 按 `elision` 同一证据标准，只用于明确的 /d/ 删除候选，并在 notes 记录对应的 elision 目标。参考侧研究项，汇总时与父类去重。 | /d/ 不爆破、清化、与相邻辅音闭合重叠或对齐零时长，均不自动等于删除；仍无法分辨时标 `uncertain`。 |

Tier 是上线策略，不能替代标注质量。以上参考研究项可以保留人工数据以供未来评估，但首轮不能因其有标签就宣称已经有用户侧检测器。本轮评估器保守排除 `label: uncertain` 或 `not_applicable` 目标的全部分类及测量指标。如果某现象分类不确定，但另一项标量已可靠测得，应为该测量另建独立 `target_id`，使用 `label: null` 并完成其独立仲裁；在 notes 记录关联目标及拆分理由。不能靠把数值附在 uncertain 目标上使其进入测量评估，也不能把同一测量在多个有效目标重复计数。

## 5. 采集、质量与数据划分

`collection_plan.json` 的 32 条自编英语提示由 8 位计划说话人各读一次：2 位 reference、6 位 learner，共 256 条计划录音。每位在四种条件下各读 8 条；使用按 8 句成组轮换的分配，使相邻配对句在同一条件。每个提示仅列现象候选，不要求或强迫某种变体，也不预填预期 `present` / `absent`。

计划条件是安静自然语速、安静较慢、安静较快和普通室内自然语速。后两种语速以说话人舒适程度为准，不设置精确字/秒目标；实际速率与设备/环境要在采集时记录。不能用加速、拉伸、叠噪或 TTS 来冒充真实条件录音。保留原文件；转换格式或派生污染版本使用新文件身份，关联同一原件，并保持同一 split。

质量检查至少包含：目标是否裁切、说话人数、可懂度、实际录音条件、明显削波、噪声/混响、响度、可用有声片段、转写一致性、是否存在可人工确认的时间边界。SNR 等尚未测得的数字保持未知。不能因为“clean”是采集目标就写成已确认质量；也不能只保留检测器容易处理的片段来提高表面成绩。

真实样本的 split 只允许 `train` / `dev` / `test`。本轮开发计划 **全部进入 dev**，train/test 计划数量均为 0，目的是完善协议、检查混淆和建立可执行测量路径；8 位说话人不足以发布面向产品人群的准确率。公开种子独立记录来源和真实入库数量，不计入这 256 条，也不自动成为测试集。

分组防泄漏必须同时满足：

- 同一实际说话人的所有角色、会话、切片、重复录音和派生音频在同一 split；不能通过换 ID 避开。
- 同一 `source_group` 的原件、切片、衍生版本和同源内容在同一 split；公开素材按原始录制/作品与语料来源追溯，不能一片一组。
- 将 speaker 和 source_group 看作连通分组约束，整个连通分量只分配一次。只分别检查两个字段但允许它们交叉连接，仍会泄漏。
- 本计划的 32 个提示属于同一自编提示组，8 位说话人共享该 `source_group`，因此全体留在 dev。未来 held-out 评估应新招募独立说话人并使用独立来源/提示组；不要事后把本轮已反复调参的数据移到 test 后宣称盲测。

真实人工基准与 `synthetic_smoke` 分开统计。合成信号可以验证解析、单位、时间映射与已知频率，不能建立真实口音、弱化、连读或产品准确率。公开语音的真实来源并不等于它已有人类金标；只有冻结的 `adjudicated` 有效记录才可进入相应人工标签评估。

## 6. 首轮交付与报告口径

交付实际音频清单及来源记录、两份独立初标、仲裁后的版本、质量/不确定统计和每个现象的可用目标数。单人标签可用于开发浏览，但不能冒充双人基准。保留未完成目标并报告完成率，不能从分母悄悄移除。

本轮 CLI 只校验格式并比较已提供的预测与人工记录，不读取音频进行声学推理，也不生成 ASR、对齐、F0 或现象预测。已经实现的评估为目标级标量 MAE、bias、coverage，以及有效二分类目标的 precision、recall、F1、缺失率和提供概率时可选的 Brier score。纯测量可用 `adjudicated` + `label: null`；分类分母只包含冻结的 `present` / `absent`。`uncertain`、`not_applicable`、`pending` 和 `single_review` 不作为负类或测量金标。

边界区间指标、逐帧 F0 曲线与倍频错误统计、标注者一致性、按条件自动分层和更完整的人工完成/拒判统计均为后续计划，不能描述为本轮 CLI 已输出。首轮人工工作仍应保存这些审核材料和各条件样本量，便于后续实现与复核。不能把采集提示数当作阳性现象数，也不能仅用格式检查成功证明声学模型有效。

所有结果需写明是 dev、真实/合成、reference/learner、协议版本、模型版本和有限说话人规模。该首轮用于开发；进入真正独立测试前另行冻结阈值、扩展说话人/来源覆盖并确定测试集。
