# Inter 4.1

Unmodified variable WOFF2 fonts from https://rsms.me/inter/:
- https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1
- https://rsms.me/inter/font-files/InterVariable-Italic.woff2?v=4.1

Copyright Rasmus Andersson. Distributed under the accompanying SIL Open Font License (`OFL.txt`, upstream v4.1). Root layout uses `next/font/local`, swap display and adjusted Arial fallback. Assets ship with the application; no external font request is made at runtime or build time. CJK and unsupported glyphs retain system fallbacks; phonetic/code text keeps the existing monospace stack.
